# Your Tutor — Bath Year 1

Live: **https://matthieu-ide.github.io/bath-study/**

Two interactive study apps for University of Bath first-year maths, built around the actual
lecture notes:

| | |
|---|---|
| [Probability & Statistics 1A](https://matthieu-ide.github.io/bath-study/probability/) | 98 pages decoded line by line, 34 animations, 30 labs, unlimited generated questions |
| [Algebra 1A](https://matthieu-ide.github.io/bath-study/algebra/) | 67 pages decoded line by line, 17 animations, 21 labs, complex numbers through determinants |

## The notes are not hosted here

The lecture notes are their authors' copyright, so this site ships no PDF. Each app asks for
your own copy the first time you open it on a device and keeps it in that browser's storage
(IndexedDB). The file is never uploaded anywhere.

Progress, mistakes and the flashcard schedule live in the same browser storage, so use the same
browser and profile to keep them. The two apps use separate databases and do not interfere.

## What's in this repository

Only the built static sites. Source lives in the `bath-smartstudy` and `bath-algebra` projects.
